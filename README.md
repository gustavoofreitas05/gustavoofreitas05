Atualmente, venho desenvolvendo conhecimentos em **Java, Python, SQL, JavaScript, Node.js e C#**, com interesse especial em backend, bancos de dados e desenvolvimento de sistemas.

Meu objetivo profissional para os próximos anos é me aprofundar em **Engenharia de Dados**, evoluindo meus conhecimentos em bancos de dados, pipelines, ETL/ELT, processamento e arquitetura de dados.

Meu objetivo é unir **programação + dados + hardware** para transformar problemas reais em sistemas inteligentes.
